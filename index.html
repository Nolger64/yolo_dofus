Pilares Técnicos del Proyecto

📊

Dataset & Roboflow MCP

Gestión automatizada de versiones conectada directamente al Model Context Protocol de Roboflow.

  • ✓ Versión 3 con 208 imágenes curadas.
  • ✓ División en 149 Train, 38 Valid y 21 Test.
  • ✓ Redimensionamiento y normalización a 512×512.
⚡

Modelo YOLO11 Nano

Arquitectura de última generación optimizada para máxima velocidad sin perder fidelidad geométrica.

  • ✓ Solo 5.4 MB de peso total en disco.
  • ✓ Backbone convolucional de alta densidad.
  • ✓ Capacidad de ejecutarse a más de 60 FPS en vivo.
☁️

Entrenamiento Acelerado

Aprovechamiento de clusters GPU en la nube para reducir drásticamente el tiempo de entrenamiento.

  • ✓ Google Colab con acelerador NVIDIA T4.
  • ✓ 50 épocas completadas en menos de 2 minutos.
  • ✓ Exportación directa a pesos productivos best.pt.
